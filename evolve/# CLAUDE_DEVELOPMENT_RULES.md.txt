# EvenTech
## Mandatory Development Rules

---

# Mission

Build EvenTech like enterprise software.

Never build demo-quality code.

Every implementation must be production-ready.

---

# Before Writing Code

Always

- Read README.md
- Read all Architecture documents
- Read the current module document
- Search the project for existing implementations
- Reuse existing components

Never start coding immediately.

---

# Never

Never duplicate components.

Never duplicate business logic.

Never duplicate Firestore queries.

Never create another button if one already exists.

Never hardcode colors.

Never hardcode spacing.

Never hardcode permissions.

Never hardcode IDs.

Never hardcode roles.
