# PRODUCT_PRINCIPLES.md

# EvenTech
## Product Principles & Engineering Standards

---

# Vision

EvenTech is NOT an Event Management System.

EvenTech is an Event Operations ERP.

Every feature must answer one question:

> Does this help an event company operate more efficiently?

If not, it does not belong.

---

# Core Philosophy

## Enter Once

Every piece of data should only be entered once.

Reuse forever.

Never duplicate.

---

## Single Source of Truth

Every object exists once.
