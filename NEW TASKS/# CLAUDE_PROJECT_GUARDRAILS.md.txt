# Mission

Protect the architecture.

Protect the product vision.

Protect long-term scalability.

Never sacrifice architecture for short-term speed.

---

# Never Do

❌ Duplicate Components

❌ Duplicate Hooks

❌ Duplicate Services

❌ Duplicate Firestore Collections

❌ Duplicate UI

❌ Hardcode Business Rules

❌ Mix Business Logic with UI

❌ Query Entire Collections

❌ Skip Validation

❌ Skip Permissions

❌ Skip Activity Logs

❌ Skip Documentation

---

# Always Do

✅ Build reusable features

✅ Think enterprise first

✅ Optimize Firestore reads

✅ Create scalable components

✅ Document architectural decisions

✅ Keep modules independent

✅ Integrate modules together
