# Architecture Goal

EvenTech is NOT a ticketing application.

EvenTech is an ERP + Operations Platform for Event Companies.

Ticketing is only one module.

Finance is a first-class module.

Operations is a first-class module.

Master Data is the foundation of the platform.

Every event should be generated from reusable company data rather than manually entered information.

Always think like you're building software for professional event production companies.
