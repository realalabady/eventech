# 41_ORGANIZER_DASHBOARD_SPEC.md

> **EvenTech Organizer Production Studio Dashboard**
>
> Version: MVP 1.0

---

# Purpose

Define the organizer experience.

The dashboard is not an admin panel.

It is a professional event command center.

---

# Main Goal

The organizer should open EvenTech and instantly understand:

* Event progress
* Current problems
* Upcoming tasks
* Team activity
* Audience growth
