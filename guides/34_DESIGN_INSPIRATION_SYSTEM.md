# Mission

This document defines **how EvenTech should look and feel**.

It is **not** a list of websites to copy.

It is a breakdown of the principles that make the world's best software feel premium.

Every designer, engineer, and AI agent must use these principles instead of copying interfaces.

---

# Primary Inspiration

## Luma

Role

The emotional foundation.

Learn from

* Large spacing
* Editorial layouts
* Premium typography
* Smooth page transitions
* Elegant gradients
* Calm interfaces
* Storytelling landing pages

Never copy

* Exact layouts
* Exact colors
* Exact illustrations

---

## Linear

Role

Professional productivity.

Learn from

* Dense but readable dashboards
* Keyboard-first UX
* Excellent hierarchy
* Minimal visual noise
* Intelligent spacing
* World-class interaction design

Never copy

* Sidebar layout
* Component styling

---

## Apple

Role

Interaction quality.

Learn from

* Motion
* Simplicity
* Precision
* Material usage
* Focus management
* Typography
* Micro interactions

Apple marketing pages.

# Visual DNA

If EvenTech were a person

It would be

Elegant

Minimal

Creative

Technical

Confident

Never flashy.

Never loud.

---

# Overall Feeling

Users should feel

"I trust this platform."

before they even interact with it.

---

# Design Language

EvenTech combines

Editorial

*

Productivity

*

Creative Studio

*

Realtime Collaboration

This combination should make the product unique.

---

# Interface Density

Marketing

Very spacious.

Organizer Dashboard

Medium density.

Admin

Higher density.

Mobile

Comfortable spacing.

---

# Color Philosophy

Dark mode first.

Muted palettes.

Accent colors used intentionally.

Gradients only where they reinforce hierarchy.

Avoid rainbow interfaces.

---

# Typography Philosophy

Typography should do most of the visual work.

Large headings.

Comfortable body text.

Minimal font weights.

Excellent rhythm.

---

# Shapes

Rounded.

Soft.

Confident.

Never sharp.

Never playful.

---

# Cards

Cards are workspaces.

Not decoration.

Every card should have

Purpose

↓

Hierarchy

↓

Action

↓

Motion

---

# Icons

Lucide only.

Icons support text.

Never replace text.

---

# Borders

Subtle.

Low contrast.

Only enough to define structure.

---

# Shadows

Soft.

Layered.

Never dramatic.

Depth comes from spacing first.

---

# Motion Identity

Motion should resemble

Moving paper.

Not bouncing objects.

Objects have weight.

Transitions preserve continuity.

---

# Scroll Experience

Scrolling should reveal information.

Not surprise users.

Sections should gently appear.

Avoid aggressive parallax.

---

# Dashboard Feel

The organizer dashboard should resemble

A creative production studio.

Not

Accounting software.

---

# Landing Page Feel

The homepage should feel like

A premium product launch.

Not

A marketing template.

Sections

* Hero
* Trusted By
* Features
* Interactive Demo
* Workflow
* Testimonials
* Pricing (future)
* CTA
* Footer

---

# Event Pages

Event pages should feel cinematic.

Large imagery.

Clear typography.

Strong call-to-action.

Simple booking flow.

---

# Organizer Profile

Organizer profiles should feel like mini websites.

Hero section.

Brand identity.

Past events.

Upcoming events.

Team.

Social links.

Gallery.

---

# Dashboard Components

Preferred style

Glass navigation.

Minimal cards.

Large metrics.

Interactive charts.

Floating command palette.

---

# Animation Identity

No exaggerated movement.

Everything eases naturally.

Shared element transitions preferred over fades.

---

# White Space

Whitespace communicates confidence.

Never compress layouts to fit more information.

---

# Trust Signals

Verified badges.

Realtime indicators.

Recent activity.

Live attendee counts.

Completion percentages.

Professional imagery.

---

# Mobile Experience

Feels like a native application.

Not a responsive website.

Bottom navigation.

Gesture-friendly spacing.

Floating actions.

---

# Visual Anti-Patterns

Never

❌ Massive gradients everywhere

❌ Neon colors

❌ Glassmorphism on every component

❌ Heavy shadows

❌ Tiny typography

❌ Cluttered dashboards

❌ Random animations

❌ Multiple visual styles on one screen

---

# Inspiration Workflow

Before designing any feature

Study

1. Luma (emotion)
2. Linear (workflow)
3. Apple (interaction)
4. Framer (presentation)
5. Arc (personality)

Then create something original that fits EvenTech.

Never recreate another company's UI.

---

# Design Review Checklist

Ask

* Does it feel premium?
* Does it reduce cognitive load?
* Is the hierarchy obvious?
* Is the motion purposeful?
* Is it consistent with the design system?
* Would it still be recognizable without the logo?

If not,

iterate.

---

# The EvenTech Identity

EvenTech should become recognizable because of

* Its motion
* Its spacing
* Its typography
* Its workflows
* Its consistency

—not because it imitates another product.

The goal is to create a visual language that people associate with EvenTech alone.

---

# Final Principle

Study the best products.

Understand **why** they feel great.

Never copy **what** they look like.

The objective is to create a product that one day becomes someone else's inspiration.
