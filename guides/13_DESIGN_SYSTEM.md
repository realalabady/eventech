# 13_DESIGN_SYSTEM.md

> **EvenTech Design System**
>
> Version: 1.0

---

# Purpose

This document defines the complete visual identity of EvenTech.

Every screen, component, animation, and interaction must follow this design language.

The design should feel like a fusion of:

* Luma
* Linear
* Vercel
* Raycast
* Apple
* Stripe
* Framer

But it must evolve into its own recognizable identity.

---

# Design Philosophy

EvenTech is **not** another dashboard.

It should feel like professional creative software.

Think:

> "Figma for event production."

The interface should feel

* Premium
* Modern
* Elegant
* Cinematic
* Spacious
* Fast
* Confident

Do not remove functionality.

Rearrange intelligently.

Touch-friendly spacing.

# Accessibility

WCAG AA minimum.

Keyboard navigation.

Visible focus.

ARIA labels.

Reduced motion.

Color contrast.

# Visual Consistency Rules

* Typography Scale
* Radius Scale
* Shadow Scale
* Motion Tokens
* Spacing Scale

No exceptions.

# Golden Rule

If a screen looks like a generic admin dashboard, redesign it.

Every page should feel like software that people enjoy opening every day.

The visual identity of EvenTech should become one of its strongest competitive advantages.
